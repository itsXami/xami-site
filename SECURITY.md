# Security policy

This repository holds the source of the Xami website (https://xami-sound.pages.dev), a static site that offers
the free Vonar plugin. It has no server, database, accounts or forms.

## Reporting a vulnerability

Please report security problems privately through GitHub's private vulnerability reporting:

- website: https://github.com/itsXami/xami-site/security/advisories/new
- the Vonar plugin or its installer: https://github.com/itsXami/vonar/security/advisories/new

Do not open a public issue for a security problem. Reports are welcome in English or Polish.

## What to report

- a way to change what the site serves, or to make it link to a different installer,
- anything that lets a third party run scripts on the site,
- a download that does not match the SHA-256 published next to the Download button,
- a site that pretends to be the official Vonar download. Official downloads are only available from
  https://xami-sound.pages.dev and https://github.com/itsXami/vonar.

## What to expect

You will get a reply when the report has been read. Confirmed problems are fixed as soon as possible and, when
users are affected, announced on the site and in the GitHub release notes.
