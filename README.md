# xami-site

Source of the Xami website — free audio plugins and presets for music producers.
First product: [Vonar](https://github.com/itsXami/vonar), a free wavetable synthesizer (VST3, Windows).

Built with [Astro](https://astro.build) and hosted on Cloudflare Pages.

Project notes (`CLAUDE.md`, `docs/`) are in Polish.
